# Security policy

If you find a vulnerability (for example a way to read another member's data, bypass sign-in or admin checks, or inject script into a page), please report it **privately** through GitHub: [Security → Report a vulnerability](https://github.com/anand1296/whetstone/security/advisories/new).

Please include what you found, how to reproduce it, and its impact. You'll get an acknowledgement as soon as possible, and credit in the fix if you'd like it. Please don't test against other people's accounts or data, and give us reasonable time to fix the issue before disclosing it.

How the app protects sessions, CSRF and content is described in the *Sign-in, sessions and invites* walkthrough ([walkthroughs/03-sign-in.md](walkthroughs/03-sign-in.md)) and in [docs/SPEC.md](docs/SPEC.md).
